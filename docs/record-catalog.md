# All-time record catalogue

Search all 282 record IDs discovered for tour R on 2026-09-24. This is a bundled
snapshot, separate from the 467 season-stat IDs. Use `pga_record_catalog()` for
current records, and `pga_all_time_records(record_id)` for the selected table.

Upstream records may contain anomalies or incomplete rounds. For example, the
lowest-18-hole-score feed included a withdrawn player's partial score of 42;
we preserve the source, not certify that it is a completed-round record.
Only selected record tables have been live-tested, not all 282.
